## 🚀 Quick Start (3 passos)

### 1️⃣ Testar a plataforma agora
Dê dois cliques no arquivo `plataforma.html` — abre no seu navegador.

**Acessos de demonstração:**
- `999999` → entra como **admin** (painel administrativo)
- Qualquer outro código de 6 dígitos → entra como **membro**

### 2️⃣ Ler a documentação
Leia os arquivos em `/docs/` na ordem numerada (01 → 07).

### 3️⃣ Colocar no ar
Siga o `docs/02-COMO-PUBLICAR.md` para hospedar gratuitamente na Vercel.

## 🛠️ Tecnologia

- **Frontend:** HTML + React 18 + Tailwind CSS (single-file)
- **Tamanho:** ~250KB (com PDFs/Excel embutidos em base64)
- **Compatibilidade:** Chrome, Edge, Safari, Firefox (desktop + mobile)
- **Offline-ready:** Funciona sem servidor após primeira carga (CDN do React/Tailwind)
- **Zero dependências externas:** Não precisa de Node, npm, build, nada.

## 📞 Próximas etapas (em ordem)

1. **Ler toda a documentação** em `/docs/` (1-2 horas)
2. **Hospedar na Vercel** (15 minutos) — vide `02-COMO-PUBLICAR.md`
3. **Configurar checkout Cakto** (30 minutos) — vide `03-CHECKOUT-E-CODIGOS.md`
4. **Editar e cortar vídeo HeyGen** (1 hora) — remover marca d'água, cortar pra 15s
5. **Configurar campanha Meta Ads** (30 min) — vide `04-GUIA-DE-ANUNCIO.md`
6. **Lançar com R$ 30/dia** por 5 dias e validar
7. **Escalar o vencedor** (R$ 50-100/dia) — vide `07-CRONOGRAMA-90-DIAS.md`
