## 🎯 Script Principal (15s) — RECOMENDADO

Versão hipnótica com PNL aplicada. Use no vídeo principal de anúncio.

```
Imagina você abrindo o WhatsApp de um fornecedor
direto da fábrica... sem precisar de indicação,
sem intermediário, sem pagar caro.

Eu reuni cento e sessenta e cinco fornecedores
verificados do Brás, Goiânia e Caruaru.
Com contato direto. Prontos pra te atender agora.

Outras pessoas cobrariam centenas por essa lista.
Você acessa tudo por apenas trinta e sete reais.
Uma única vez. Pra sempre.

Toca no link e começa hoje.
```

**Contagem:** 73 palavras · ~17 segundos
**Técnicas PNL usadas:**
- "Imagina você..." → comando embutido + future pacing
- "sem... sem... sem..." → ritmo ternário hipnótico
- "Outras pessoas cobrariam centenas..." → ancoragem de preço
- "Toca no link e começa hoje" → duplo comando embutido

### Timing detalhado para gravar

| Tempo | Fala | Performance |
|---|---|---|
| 0s-3.5s | "Imagina você abrindo o WhatsApp..." | Tom suave, íntimo, olhar direto |
| 3.5s-5.5s | "...sem indicação, sem intermediário, sem pagar caro" | Tom cresce, nega com cabeça |
| 5.5s-9s | "Eu reuni 165 fornecedores verificados..." | Firme, mostra celular |
| 9s-10s | "Prontos pra te atender agora" | Pausa antes de "agora" |
| 10s-12s | "Outras pessoas cobrariam centenas..." | Tom de revelação |
| 12s-14s | "Uma única vez. Pra sempre." | Pausa de 0.5s entre frases |
| 14s-15.5s | "Toca no link e começa hoje" | Aponta pra baixo |

## 🎬 Como gerar o vídeo

### Opção 1 — HeyGen (avatar IA falando)
1. Acesse https://heygen.com
2. Escolha um avatar feminino brasileiro (várias opções)
3. Cole o script
4. Configure voz natural brasileira (várias vozes femininas disponíveis)
5. Gere o vídeo
6. **Remova a marca d'água no CapCut** depois

### Opção 2 — Você mesmo(a) grava
1. Celular fixo no tripé
2. Iluminação natural (perto de janela)
3. Fundo organizado: rack com roupas + caixa + mesa
4. Decore o script e grave em vários takes
5. Edite no CapCut

### Opção 3 — Voz IA + imagem animada
1. Gere áudio no ElevenLabs ou Play.ht
2. Gere imagem no Midjourney/Flux (veja `06-PROMPTS-PARA-IMAGEM-IA.md`)
3. Anime no Runway/Kling/Luma
4. Sincronize tudo no CapCut

---

## 💡 Dicas de performance

1. **Olhe diretamente pra câmera** durante toda a fala
2. **Mostre o celular pelo menos uma vez** no meio
3. **Sorria genuinamente** no momento "Pra sempre"
4. **Pausa de 0.5s** após "Outras pessoas cobrariam centenas..."
5. **Não use música** se você está falando — só efeito sonoro sutil
6. **Adicione legendas** no CapCut (85% assiste sem som)
